关于与开源许可

空天文件转换是一个纯静态、本地运行的格式转换工具。所有文件都在浏览器内处理，不会上传到任何服务器；可直接部署到 GitHub Pages 或局域网静态服务器。

功能参考

PDF 工具集的功能设计与交互参考了 BentoPDF（github.com/alam00000/bentopdf）。BentoPDF 以 AGPL-3.0 许可发布（另提供商业授权）。本项目未直接复制其源代码，PDF 操作基于 pdf-lib / pdf.js 独立实现；若未来引入其源码，本项目整体将按 AGPL-3.0 发布并保留其版权声明。

已知限制

PDF 加密/解密、OCR、Office→PDF（LibreOffice WASM）等能力需要额外 WASM 或原生组件，当前版本未内置；在 GitHub Pages 与局域网 HTTP 环境下也无法启用 SharedArrayBuffer，因此不提供多线程加速。

工具箱

对任意文件计算摘要，结果可复制或保存为 .txt。大文件为一次性读入内存计算。

把文本类文件从一种编码转为另一种，输出会立即下载。

支持粘贴或选择文件；可格式化缩进，也可压缩为单行。

按 UTF-8 处理文本；解码失败时会提示无效内容。
